# Máquina Virtual

No link abaixo vou deixar disponivel uma maquina virtual com o ubuntu 18.04, configurado já com os pacotes do ros, como o rosaria, sicktoolbox e os outros pacotes que forão desenvolvidos durante a disciplina. Basta baixar esse arquivo e importar a máquina virtual no oracle virtualbox.


```bash
rosrun sicktoolbox_wrapper sicklms _port:=/dev/ttyS1
```

Para importar essa máquina no oracle virtualbox, basta descompactar o arquivo zip baixado e acessar no menu superior, arquivo -> importar Appliance e selecionar o arquivo **.ova** .

**OBS:** Lembre-se de configurar a máquina com a quantidade de memória RAM disponível em sua máquina, modificar a placa de rede e alterar a quantidade de núcleos do processador para se ter um bom desempenho.
