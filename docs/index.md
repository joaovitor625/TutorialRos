# Bem-vindo ao Tutorial de ROS!

Este site serve como um guia prático para a configuração e utilização do **Robot Operating System (ROS)**, com foco em aplicações práticas de robótica.

O objetivo é criar um material de consulta rápido e direto ao ponto, facilitando o desenvolvimento de projetos.

---

Este tutorial foi desenvolvido por **João Vitor Barbosa Pinheiro** como parte fundamental das atividades da disciplina de **Robótica Avançada**, ministrada na **Universidade Federal de Itajubá (UNIFEI)**.

## Como Usar este Site

### 1. Navegação

O conteúdo é dividido em capítulos, cada um focado em um componente ou tarefa específica (como conectar um Lidar, configurar o robô, etc.).

Você pode navegar livremente por todos os tópicos usando o **menu lateral** para encontrar a seção que mais lhe interessa.

### 2. Copiando os Comandos

Para facilitar seu trabalho, você não precisa digitar os comandos manualmente!

> **Dica Importante!**
>
> Todos os blocos de código e comandos de terminal neste site possuem um **botão de cópia** automático.
>
> Basta clicar no **ícone de duas folhas**  que fica visível no canto superior direito de qualquer bloco de código. O conteúdo será copiado para sua área de transferência, pronto para ser colado no terminal.
